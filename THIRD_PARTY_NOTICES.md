# Third-party notices

FauxGo is MIT-licensed. Runtime and development dependencies retain their own licenses; consult `package-lock.json` and each package's license before distribution.

Notable components include Expo and React Native (MIT), Expo Router (MIT), MapLibre React Native (BSD-2-Clause) and MapLibre GL JS (BSD-3-Clause), React Native SVG (MIT), Material Design Icons through `@expo/vector-icons` (Apache-2.0), AsyncStorage (MIT), Vitest (MIT), and Playwright (Apache-2.0).

Map data/style attribution is provider-specific and must remain visible in the rendered map. The default basemap is OpenFreeMap's Positron style, with OpenFreeMap, OpenMapTiles and OpenStreetMap attribution supplied by the style. The no-connection fallback contains no map data. The exact MapLibre GL JS worker license is copied beside its generated same-origin worker files before export.

Food and produce photographs in `assets/photography` were generated specifically for FauxGo, not scraped or sourced from restaurant catalogs. Category photography is illustrative and must not be presented as an exact photograph of every generated menu item. Source prompts and derivative details are in `docs/ASSETS.md`.

This notice is a convenience summary, not a substitute for the license texts distributed by each dependency.
