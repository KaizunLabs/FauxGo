# Contributing

Thank you for improving FauxGo. Keep changes focused, typed, accessible, and verifiable.

1. Open an issue for significant product or architecture changes.
2. Install with `npm ci`.
3. Create a focused branch and preserve established patterns.
4. Add or update tests for domain behavior.
5. Run `npm run verify` before opening a pull request.

All names, businesses, operators, menus, vehicles, and images must be original or licensed for repository distribution. Do not contribute copied interfaces, trademarks as service names, scraped catalogs, real driver data, real addresses, partner APIs, payment collection, phone/SMS links, or code capable of making a real booking or transaction.

UI work must cover narrow mobile, tablet, desktop, keyboard focus, screen-reader labels, light/dark appearance, and reduced motion as relevant.
