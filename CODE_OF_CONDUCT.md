# Code of Conduct

We pledge to make participation in FauxGo welcoming and harassment-free for everyone. Be considerate, discuss ideas rather than people, respect privacy, accept constructive feedback, and give credit for others’ work.

Unacceptable behavior includes harassment, discrimination, sexualized attention, threats, doxxing, impersonation, or publishing another person’s private information. Project maintainers may remove contributions or participation that violate these expectations.

Report conduct concerns privately to the repository owner through their verified GitHub profile until a dedicated moderation address is published. Maintainers must handle reports confidentially, fairly, and without retaliation.
